# Cost Optimization Decision Records

Create one decision record for each material optimization. A decision record explains why a change was considered, what evidence supports it, how the impact is estimated, and how safety and rollback are handled.

Copy `TEMPLATE.md` into a numbered file, for example `001-compute-right-sizing.md`. Do not record a saving as actual until it is supported by reconciled before/after billing evidence.

## Minimum review requirements

- Cite the evidence artifact paths and collection dates.
- Separate measured facts from assumptions and estimates.
- Include alternatives considered, operational impact, and approval.
- State validation criteria and rollback steps.
- Do not include credentials, account IDs, public IPs, or unnecessary resource identifiers in public records.
